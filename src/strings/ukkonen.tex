\subsection{Algoritmo de Ukkonen}

Constrói uma árvore de sufixos para uma string $s$ de tamanho $n$ em $O(n \log k)$ em que $k$ é o tamanho do alfabeto.

A função build\_tree constrói a árvore de sufixos. Ela é guardada num array de estruturas node onde node[0] é a raiz.
