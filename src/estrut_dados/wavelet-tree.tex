\subsection{Wavelet tree}

Imagina que você tem uma array de inteiros. Essa estrutura 
permite você:

\begin{enumerate}
    \item computar o $k$-ésimo menor valor de um segmento 
    \item Dado um índice $i$, dar swap nos índices $i$ e $i+1$
    \item Colocar um cara no final da array
    \item Tirar um cara do final da array
    \item Encontrar a quantidade de vezes que números de $x$ até $y$
          aparecem em um determinado intervalo. 
\end{enumerate}
