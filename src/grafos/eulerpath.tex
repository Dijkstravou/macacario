\prob{1}{Caminho Euleriano} Dado um grafo não direcionado $G$, de $N$ vértices e $M$ arestas um \textbf{Caminho Euleriano} é uma sequência de vértices
$(v_0, ..., v_M)$ e uma sequência de arestas $(e_0, ..., e_{M-1})$ que satisfaça as sequintes condições: 

\begin{itemize}
    \item $(e_0, ..., e_{M-1})$ é uma permutação de $(0, ..., M-1)$
    \item Para $0 \leq i < M-1$ a aresta $e_i$ conecta $v_i$ e $v_{i+1}$
\end{itemize}
