\prob{1}{2-sat} Desejamos selecionar valores booleanos para variáveis $x_1, x_2, x_3... x_n$ para satisfazer uma 
expressão booleana (SAT). A expressão deve estar em CNF (forma normal conjuntiva), que é a conjunção de várias cláusulas,
onde cada cláusula é uma disjunção de literais (variáveis ou negação de variáveis). O 2-SAT é uma restrição do problema onde
cada cláusula tem apenas 2 literais. Exemplo em 3 variáveis:

\[ (a \lor \neg b) \land (\neg a \lor b)\land (\neg a \lor \neg b) \land (a \lor \neg c) \]
