# macacario
Macacário para marotanas de programação estilo ICPC.

# Build

Primeiramente, instale alguma distruibuição de latex (testado usando texlive).

Tem dois tipos de processo de build: o "fast", que compila apenas uma vez mas deixa o sumário quebrado, e o completo, chamado só de "build".

Então, para compilar rápidamente, use "make fast", e para compilar o completo, "make build" ou só "make".
